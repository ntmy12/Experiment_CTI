# Pilot Experiment H2.1: Prefix Sensitivity and Visual Contribution in Vision-Language Models

> **Scientific Objective:** Pilot experiment to test hypothesis **H2.1** on the vision-language model **LLaVA-1.5-7B** (greedy captioning on COCO val2014, 20 sampled images):
> - **(P0, Premise / Reproduction):** Visual contribution ($V_t$) decreases as generation proceeds to later token positions ($t$).
> - **(P1):** The probability that a generated object changes when a preceding token is changed increases with the object's position in the generated text ($S_t$, flip rate).
> - **(P2):** At the same position, objects with *low* visual contribution ($V_t$) change more easily ($S_t$ is higher).
>
> ⚠️ **Scope Notice:** This is an exploratory pilot with $n=20$ images designed to validate the end-to-end pipeline and assess effect directions. All empirical estimates are explicitly reported as **"exploratory ($n=20$ images)"** using cluster bootstrap confidence intervals.

## 1. Mathematical Definitions

| Concept / Symbol | Formal Notation | Operational Definition |
| :--- | :--- | :--- |
| **Prefix** | $y_{<t}$ | Tokens generated by the model before position $t$ (excluding prompt & image tokens). |
| **Object Token** | $y_t$ | Generated token at 0-based position $t$ that is the first token of a word in the restricted object vocabulary ($K$ single tokens). |
| **Relative Position** | $\text{rel\_pos}$ | $\text{rel\_pos} = t / T$, where $T$ is total generated caption length. |
| **Restricted Distribution** | $p(\cdot)$ | Softmax over logits of *only* the $K$ object vocabulary token IDs, cast to Float32 and renormalized. |
| **Visual Contribution** | $V_t$ | $V_t = \text{JSD}(p(\cdot \mid \text{image}, y_{<t}), p(\cdot \mid \text{no image}, y_{<t}))$ under teacher forcing. |
| **Prefix Perturbation** | $y'_{<t}$ | Replacement of token $y_s$ ($s \in [t-8, t-1]$) with rank-1 plausible alternative token $a$ from the model's full-vocab distribution. |
| **Prefix Sensitivity** | $S_t$ | $S_t = \text{JSD}(p(\cdot \mid \text{image}, y_{<t}), p(\cdot \mid \text{image}, y'_{<t}))$. |
| **Argmax Flip** | $\text{flip}$ | $\text{flip} = 1$ if $\text{argmax}_{o \in \text{obj}}(p_{\text{orig}}(o)) \ne \text{argmax}_{o \in \text{obj}}(p_{\text{pert}}(o))$, else $0$. |
| **Jensen-Shannon Div** | $\text{JSD}$ | Base-2 JS divergence (squared JS distance): $\text{JSD}(p, q) = \frac{1}{2} D_{KL}(p \parallel m) + \frac{1}{2} D_{KL}(q \parallel m) \in [0, 1]$. |

## 3. How to Run

### Option A: Turnkey Execution on Kaggle (Recommended)
Target environment: **2 x NVIDIA T4 (16 GB each)**.

1. Create a Kaggle notebook and set **Accelerator: GPU T4 x 2** and **Internet: On**.
2. Upload this repository or open [`run_kaggle.ipynb`](run_kaggle.ipynb).
3. Execute the cells sequentially. Cell 3 runs the complete pilot:
   ```bash
   python -u run_pilot.py --n_images 20
   ```
4. View [`results/report.html`](results/report.html) rendered directly in the notebook using `IPython.display.HTML`.

### Option B: Local CLI Execution
Ensure dependencies are installed:
```bash
pip install -r requirements.txt
```

Run unit tests:
```bash
pytest tests/test_h21.py -v
```

Execute pilot pipeline:
```bash
python -u run_pilot.py --n_images 20 --val2014_dir /path/to/val2014 --instances_json /path/to/instances_val2014.json
```

8. **`report.html`**: Standalone HTML document with all figures embedded as base64 images, definitions table, and interpretation guide.

## 6. Interpretation Protocol

- **P1 Supported:** Sensitivity $S_t$ and flip rate monotonically increase across position bins ($t$), and Spearman($S_t$, $t$) $> 0$.
- **P2 Supported:** Within position bins, $S_t$ correlates negatively with visual contribution $V_t$, and regression coefficient $b_{V_t}(M2) < 0$.
- **Mediation Indicated:** Standardized position coefficient decreases substantially from model $M1$ to $M2$ (proportion mediated $> 20\%$). If unchanged, position operates through non-visual channels (language model prior, confidence, syntax).
